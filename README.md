# Water Quality Monitor

نمونه اولیه سامانه ثبت و تحلیل داده‌های کیفیت آب — تیم **Nexora**.

## وضعیت پروژه: 100% — Prototype Complete

### قابلیت‌ها
- ثبت pH، دما، اکسیژن محلول (DO) و هدایت الکتریکی (EC)
- ثبت محل، زمان و توضیحات نمونه
- داشبورد و نمایش آخرین اندازه‌گیری‌ها
- سوابق، جستجو و فیلتر بازه زمانی
- حذف رکورد با تأیید کاربر
- آمار خلاصه و میانگین شاخص‌ها
- نمودارهای روند با Chart.js
- تشخیص مقادیر خارج از محدوده‌های مرجع نمونه
- صفحه هشدارها
- خروجی CSV سازگار با Excel
- تست خودکار منطق آماری و ارزیابی
- مستندات اجرای نسخه تحویلی

### فناوری‌ها
Java 21 · Spring Boot 3 · Spring MVC · Thymeleaf · Spring Data JPA · MySQL/H2 · Bootstrap RTL · Chart.js · Maven

### اجرای سریع
```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```
سپس: `http://localhost:8080`

### تست
```bash
mvn test
```
